# Security/Correctness Audit — v3.2.3 (native compressed + filtered sampling, Phase TS.6–8), 2026-06-16

**Scope:** the v3.2.3 Phase-TS.6–8 diff vs the `3.2.2` tag — native AMD
block-compressed (BC) sampling + bilinear/scaled filtering:
`backend_native_pm4.cyr` (TS.6 `native_sdma_build_copy_tiled` COPY_TILED_SUB_WINDOW),
`backend_native.cyr` (tiled `create_2d_sampleable`, `native_tex_tiled_params` /
`native_tex_build_tiled_copy_packet`, L2T/T2L tiled write/read + the one-shot DMA
submit, the per-draw scale write + `bind_for_sample` S# rebuild, the
`NATIVE_TEXCOMP_SUPPORTED` caps gate + `native_texfmt_sampleable`),
`backend_native_shaders.cyr` (the `image_sample` FS, the scaled FS s_load/v_mul,
per-format `DST_SEL`, `native_gfx9_image_descriptor` epitch),
`backend_native_amdgpu.cyr` (the `_native_bo_create_domain` partial-create fix),
`color.cyr` (the `int_ratio_to_f32` float shim).

**Method:** descriptor/shader/packet bytes sourced from the authoritative Mesa
`gfx9.json` (IMG_DATA_FORMAT / SQ_IMG_RSRC / SQ_IMG_SAMP + the ETC2/ASTC enum
check) and assembled/round-tripped through `llvm-mc -mcpu=gfx90c` (both textured
FS), each byte CPU-pinned. Three P(-1)-style adversarial review workflows then
re-verified the integration against source, each finding independently confirmed:
`ts7c2-review` (3 dims: GFX9 descriptor / memory-sizing / guard-bounds),
`ts7c3-review` (2 dims: resource-lifecycle / correctness-consistency),
`ts7c4-review` (2 dims: oracle-correctness / cap-flip-family). Plus a grounded
design workflow (`bilinear-design`, 3 lenses) ahead of TS.8.

**Result:** **0 CRITICAL**, **2 HIGH→fixed**, several MED/LOW→fixed, all before
the cut. The full BC path (BC1/BC3/BC4/BC5/BC7) is HW-verified pixel-exact on
Cezanne (`native_compressed_sample_e2e` vs a CPU decode); bilinear is HW-verified
(`native_bilinear_sample_e2e`, POINT-vs-BILINEAR discriminator).

## Confirmed findings (fixed)

### HIGH
- **BC6H wrong-result, silently enabled (ts7c4).** The BC family cap admitted
  BC6H, but it is HDR unsigned-float (T# NUM_FORMAT=FLOAT) decoded into an
  RGBA8_UNORM render target → clamped/quantized garbage. **Fix:** reject BC6H
  per-format in `create_2d_sampleable` (`native_texfmt_sampleable`) until an HDR
  RT path exists; CPU-asserted.
- **Per-format DST_SEL — channel broadcast (ts7c4 breadth → caught on HW).** The
  T# used identity `X/Y/Z/W` for all formats; a 1-channel BC4 sampled `(R,R,R,R)`
  instead of `(R,0,0,1)` (identity W broadcasts the present channel). Surfaced by
  *adding* the BC4/BC5 sample probes the breadth finding demanded. **Fix:**
  per-format DST_SEL (BC4→X001, BC5→XY01, ETC2_RGB→XYZ1; else identity), byte-
  pinned + HW-verified.

### MEDIUM
- **Dead-end resource (ts7c2).** Compressed `create_sampleable` returned a tiled
  texture the public write API couldn't yet populate. **Fix:** a pre-ioctl caps
  gate (`NATIVE_TEXCOMP_SUPPORTED`) — create returns 0 until the path is wired +
  HW-verified.
- **Staging-VA leak (ts7c3).** The tiled copy bump-allocated a fresh GPU VA per
  write/read from the forward-only texture region (~32K-copy exhaustion). **Fix:**
  a dedicated, re-used `_NATIVE_STAGING_VA` slot.
- **Test green-for-wrong-reason (ts7c2).** The compressed-create reject assert
  passed via a fake-fd ioctl failure, not the gate. **Fix:** the caps gate makes
  it a genuine pre-ioctl reject; test updated.

### LOW
- **Partial-create GEM handle leak (ts7c3)** — `_native_bo_create_domain` left a
  live handle on a mid-create mmap failure; root-fixed (closes the handle), fixing
  all 4 callers codebase-wide.
- **Clock-before-submit UAF window + errno-preserving error class (ts7c3)** on the
  one-shot DMA submit. Fixed (deadline computed before submit; `_native_neg_rc_to_gpu_err`).
- **epitch contract (ts7c2)** — the SDMA write path must use `awb-1` (the aligned
  block pitch), not the TS.6 round-trip's `wb-1`. Enforced by deriving epitch from
  the same `native_tex_tiled_params` the T# uses; HW-verified on a non-aligned BC1.
- **Probe-buffer overflow** in the sample e2es (`var X[N]` is N bytes) — fixed
  (`[64]`/`[40]`); a latent test bug that passed only by stack-layout luck.

## HW gaps (flagged, not bugs)
- **ETC2/ASTC** — HW-blocked on AMD (`vulkaninfo`: BC=true, ETC2/ASTC=false).
  Cap stays BC-only. See `project_etc2_astc_cezanne_black` memory.
- **BC6H** — needs an HDR render-target path (gated off).
- **Unnormalized bilinear edge fidelity** — a documented convention limitation;
  the normalized-UV path is the edge-faithful follow-on.
