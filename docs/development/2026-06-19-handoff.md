## Counting test assertions (the gotcha)

`tests/tcyr/texture.tcyr`'s summary line starts with a NUL byte → `grep`/`awk` treat
it as binary and **silently drop texture's 207**. `make test | grep` reports 4315,
but the true total is **4522**. Always count with `./scripts/count-test-assertions.sh`.

## Environment + working rules (load-bearing)

- **The dev box IS the Cezanne GPU** (`/dev/dri/renderD128`). Native compute /
  render / compiler HW e2e programs run here directly — not "HW-gated." Only the KMS
  surface path (modeset / page-flip / present) needs DRM master.
- **Never edit `lib/*.cyr` or symlink `lib/`** — it's populated by `cyrius deps`;
  writes leak into the cyrius repo. Fix stdlib upstream, bump the pin, re-resolve.
- **Tests are the way** — every new code path adds an assertion. Stack-local
  `var buf[N]` for test buffers (heap exhausts the bump allocator); pass `&buf`.
- **Verify suites by EXIT CODE, not grep-for-failed** — a segfaulting `.tcyr` prints
  no summary, so a `grep failed` falsely passes it.
- **The user handles all git** — do not commit / push. Never use `gh`; curl the
  GitHub API.
- **cyrlint untracked-deferral is a HARD CI GATE** (≥ 6.2.19) — track real work with
  a CHANGELOG / roadmap / issue pointer; avoid `later` / `future` / `NOT_IMPLEMENTED`
  trigger phrases in comments + assert strings (or `#skip-lint` the false positives).
- **Adversarial review + research via Workflow** — the v3.4 cuts used read-only
  Explore review agents over the untrusted-input parsers and an AA.4a research
  workflow over GFX9 tiling. Lean on these for substantive bites.
