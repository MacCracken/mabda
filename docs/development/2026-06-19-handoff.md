## Where 3.2.12 left things

- **Phase F is complete and released.** The native SPIR-V→GFX9 compiler emits
  `V_*_F64` for the conformant f64 **arithmetic** toolkit (add/sub/mul/div/sqrt/
  fma, i32↔f64 + f32↔f64 convert, OpConstant, Ldexp, ordered compares, OpSelect),
  HW-verified bit-exact on Cezanne. `MABDA_NATIVE_F64 = 1`;
  `gpu_caps_native_shader_f64()` returns 1. A consumer kernel compiles + runs

  the F.9 layernorm smoke).
- **Transcendentals are arithmetic-only.** GLSL.std.450 Exp/Log/Pow are f32-only
  (spirv-val rejects f64), so consumers (attn11) hand-roll exp/ln/tanh/pow as
  polynomials over the toolkit. A degree-13 exp macro was built and backed out as
  uninvocable. Do **not** re-attempt them as OpExtInst intrinsics.

## Gotcha that will bite you (now documented + scripted)

**Counting test assertions.** `tests/tcyr/texture.tcyr`'s summary line begins with
a NUL byte → `grep`/`awk` treat it as binary and **silently drop texture's 207**.
`make test | grep` therefore reports **3776**, but the true total is **3983**. This
has fooled humans *and* a review agent that was explicitly warned. Always count with
`./scripts/count-test-assertions.sh` (strips NULs, runs per-file). The NUL is a
latent cosmetic defect in texture.tcyr's print path — not yet root-caused.

## Environment + working rules (load-bearing)

- **The dev box IS the Cezanne GPU** (`/dev/dri/renderD128` present). Native compute/
  render/compiler HW e2e programs run here directly — they are **not** "HW-gated."
  Only the KMS surface path (modeset/page-flip/present) needs DRM master.
- **Never edit `lib/*.cyr` or symlink `lib/`** — it's populated by `cyrius deps` and
  writes leak into the cyrius repo. Fix stdlib upstream, bump the pin, re-resolve.
- **Tests are the way** — every new code path adds an assertion. Stack-local
  `var buf[N]` for test buffers (heap exhausts the bump allocator). Pass `&buf`.
- **The user handles all git** — do not commit/push. Never use `gh`; curl the GitHub
  API. `cyrius fmt --check` mis-passes args — use `cyrfmt --check <file>` directly.
- **cyrlint untracked-deferral is a HARD CI GATE** since 6.2.19 — track real work
  with a docs/roadmap/CHANGELOG pointer; avoid "later/future bite" trigger phrases.
